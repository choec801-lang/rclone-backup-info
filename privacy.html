RCLONE-BACKUP

개인정보처리방침

시행일: 2026년 10월 29일

1. 목적과 사용 대상

rclone-backup은 소유자 본인의 PC 파일을 본인의 Google Drive에 백업하기 위한 개인용 도구입니다. 운영자와 이용자는 동일한 개인이며, 일반 이용자를 대상으로 회원가입이나 별도의 서비스를 제공하지 않습니다.

2. 처리하는 정보와 이용 목적

  • 백업 파일의 내용, 이름, 폴더 경로, 파일 크기와 수정 시각: 백업 대상 확인, 전송 및 변경 사항 비교에 사용합니다.
  • Google Drive의 파일·폴더 식별자와 관련 메타데이터: 백업 위치 확인, 파일 조회·업로드·변경 및 이전 버전 보관에 사용합니다.
  • Google OAuth 인증 토큰과 클라이언트 설정: 승인된 계정의 Google Drive에 연결하는 데 사용합니다.
  • 실행 시각, 파일 이름, 전송 결과와 오류 메시지 등의 로그: 백업 상태 확인과 오류 해결에 사용합니다.

3. 전송과 저장

백업 파일은 사용자 PC에서 rclone을 통해 Google Drive로 전송됩니다. 별도의 앱 운영자 서버에 백업 파일을 수집하지 않습니다. 인증 정보와 실행 로그는 사용자 PC에 저장하며, 백업 파일과 이전 버전은 사용자의 Google Drive에 저장합니다.

이 안내 웹사이트에는 실제 백업 파일, 파일 목록, 실행 로그 또는 인증 정보를 게시하지 않습니다.

4. 제3자 제공 및 AI 이용

백업 저장을 위해 Google Drive를 이용합니다. 이 도구는 백업 파일을 판매하거나 광고 목적으로 제공하지 않으며, 파일 내용을 AI 모델에 전송하거나 AI 학습에 사용하지 않습니다. Google의 서비스 제공 과정에서 처리되는 정보에는 Google의 관련 정책이 적용됩니다.

5. 보관과 삭제

클라우드 백업 파일과 이전 버전은 사용자가 Google Drive에서 직접 삭제할 때까지 보관합니다. PC 원본을 삭제하는 것만으로 클라우드 백업이 삭제되지는 않습니다.

인증 정보는 재인증 과정에서 갱신되거나 사용자가 로컬 설정에서 삭제할 때까지 PC에 보관됩니다. 실행 로그는 설정된 크기와 보관 개수에 따라 순환 보관하며, 사용자가 직접 삭제할 수도 있습니다.

6. 이용 중지와 접근 권한 철회

사용자는 Windows 작업 스케줄러에서 자동 백업을 중지할 수 있습니다. Google 계정의 연결된 앱 설정에서 이 도구의 접근 권한을 철회할 수 있으며, 철회 이후에는 새로 인증하기 전까지 Google Drive에 접근할 수 없습니다.

접근 권한 철회만으로 기존 백업 파일이나 PC에 저장된 설정·로그가 삭제되지는 않습니다. 해당 정보의 삭제가 필요하면 각 저장 위치에서 별도로 삭제합니다.

7. 안내 웹사이트

이 안내 페이지는 GitHub Pages에서 호스팅합니다. 페이지에 자체 분석 도구, 광고, 입력 양식 또는 추적 스크립트를 설치하지 않습니다. 호스팅 서비스 제공 과정에서 GitHub가 처리하는 접속 정보에는 GitHub의 개인정보처리방침이 적용됩니다.

8. 관리 및 변경

백업 설정과 저장된 정보는 소유자 본인이 관리합니다. 도구의 정보 처리 방식이 변경되면 이 페이지의 내용을 갱신합니다.
